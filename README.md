# Maid-in-Korea

> 본 프로젝트는 한국에 있는 메이드카페의 홍보 및 정보 제공 목적으로 만들어졌습니다.

## 1. 기능 설계

1. 일반 회원
   1. 본 서비스의 일반 회원은 메이드 카페 이용 예정 대상자의 범위에서 서비스를 제공함
   2. 로그인 / 회원가입 기능
   3. 위치 기반 메이드 카페 조회 기능
   4. 메이드카페 상세 정보 조회 기능
      1. 메이드카페의 상세 정보는 다음과 같은 정보를 포함함
      2. 메이드카페의 상호명, 대표 이미지, 월별 스케줄
      3. 메이드카페의 메뉴 및 서비스의 이름/가격/이미지
      4. 메이드카페의 메이드 Feed
   5. 메이드카페 즐겨찾기 기능
   6. 커뮤니티 게시글 작성 및 댓글 작성 기능
   7. 회원 탈퇴 기능
   8. 신고 및 문의 기능
2. 관리자
   1. 본 서비스의 관리자는 메이드카페를 운영하고 있는 대상자의 범위에서 서비스를 제공함
   2. 관리자 로그인 / 회원가입 기능
      1. 관리자 로그인 / 회원가입 페이지는 별도의 URL을 통해 접속
      2. 회원가입은 실제 영업중인 업장인지 확인 후 개발자의 직접 승인을 통해 이루어짐
      3. 개발자의 승인 후 관리자 고유의 ID 및 PASSWORD를 생성 후 제공
   3. 사업장의 상호명 등록/수정 기능
   4. 사업장의 대표 이미지 및 커버 이미지 등록/수정 기능
   5. 사업장의 운영 시간 등록/수정/삭제 기능
      1. 운영 시간은 월 단위로 저장됨
      2. 운영 시간에는 메이드들의 근무 스케줄을 포함함
   6. 사업장의 메뉴 및 서비스 등록/수정/삭제 기능
      1. 메뉴 및 서비스는 이름, 가격, 이미지를 각각 1개씩 포함
   7. 메이드 등록/삭제 기능
      1. 메이드는 별도의 메이드 계정과 메이드 프로필을 보유
      2. 관리자는 메이드 프로필의 고유 ID를 통해 해당 메이드 프로필에게 등록 요청을 보낼 수 있음
      3. 등록은 메이드의 승인 후 이루어짐
   8. 가게 공지 등록/수정/삭제 기능
3. 메이드
   1. 본 서비스의 메이드는 메이드카페에서 근무 또는 근무 예정인 대상자의 범위에서 서비스를 제공함
   2. 메이드 로그인 / 회원가입 기능
      1. 일반 회원의 로그인 / 회원가입 페이지에서 접근할 수 있음
   3. 메이드 프로필 생성/수정/삭제 기능
      1. 본 기능은 한 메이드가 다수의 가게에서 다른 이름으로 활동할 경우를 고려하여 제작함
      2. 한 메이드 계정은 다수의 메이드 프로필을 생성/수정/삭제 할 수 있음
      3. 메이드 프로필은 고유 ID, 이름, 소개글, 다수의 SNS 계정 정보를 등록할 수 있음
   4. 메이드 프로필 Feed 기능
      1. 메이드 프로필은 하나의 고유한 Feed를 가짐
      2. Feed에는 메이드의 이름, 소개글, SNS 정보, 근무중인 메이드카페를 표시
      3. 메이드는 자신의 Feed에 사진, 영상이 포함된 게시글을 생성/수정/삭제할 수 있음
